# AERIX — first cinematic iteration

Open **http://127.0.0.1:8765/site/** while the project server is running.

This is a complete local first iteration: a real scroll-controlled drone, eight narrative chapters, reversible disassembly and folding, and an interactive explorer with all four interior layers. The mobile and reduced-motion experience uses six transparent native Blender renders. Mobile visitors can load the real model explicitly through **Explore in 3D**.

## Run

There is no build step. From the project root, if the existing server is stopped:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Then visit `/site/`. Keep the existing server if port 8765 is already in use. Opening `index.html` directly with `file://` will not load ES modules or the model. The entire `site/` directory is portable to a static HTTP host. All fonts, scripts, decoder files, textures and geometry are local; no runtime CDN or account is required.

## Experience and controls

- Scroll through form, complete architecture, battery, computer, optics, reassembly and folding. Scroll backward to reverse the same motion.
- Header links and the right-hand chapter index jump to composed views.
- **Motion on/off** switches between the real-time story and static renders; the choice is saved locally.
- **Explore in 3D** opens an orbit view. Select Flight, Architecture, Battery, Thermal, Computer, Tray, Optics or Folded. Drag to rotate, wheel/pinch to zoom, or focus the canvas and use arrow keys and `+`/`−`.
- Escape or Close returns to the same place and pose in the story. The final replay link returns to the hero.

## Art direction

Sculptural titanium against carbon, warm ivory typography and restrained copper details. Instrument Sans provides the display voice; IBM Plex Mono gives the indices and annotations a precise rhythm. Product copy describes the modeled design without invented performance, price or availability claims.

## Where to tune

| File | Control |
| --- | --- |
| `styles.css` | `:root` palette/type/spacing, chapter heights, responsive breakpoints and text sizing |
| `main.js` | `MOTION`: 1.15-second Lenis duration, `expo.out` UI easing, 0.9-second reveals |
| `js/story.js` | `VIEWS`: camera direction, distance and horizontal composition; `sampleStory`: pose sequencing and reveal timing |
| `js/scene.js` | Lighting, exposure, pixel-ratio cap, model loading and orbit behavior |
| `index.html` | Product copy, chapter order, labels and calls to action |
| `design-brief.md` | Creative decisions for this iteration |

One GSAP ticker advances Lenis and the on-demand renderer; ScrollTrigger reads the same scroll position. Every assembly pose is recomputed from scroll position. The renderer rests when the story is still and suspends when static mode is active. The body closes before the arms fold.

## Assets and reproducibility

`assets/aerix-v01.glb` is **10,958,512 bytes**, reduced from the preserved 93,945,428-byte V30 review export. All seven animation clips and 45 animated pivot names remain. Draco compresses geometry; maximum-1024-pixel WebP textures retain lossless normal maps. Compatible static primitives are grouped under their animated owners.

The optimization tooling is separate from the website:

```sh
cd scripts/web
npm ci
cd ../..
node scripts/web/optimize-model.mjs
node scripts/web/verify-story.mjs
node scripts/web/prepare-images.mjs
```

Native posters are generated by `scripts/blender/render_site_v01.py` from `blender/aerix-interior-v30.blend`. Browser checks are in `scripts/web/verify-site.cjs` and `compare-runtime.cjs`; their Playwright import currently points to this workstation's bundled runtime and should be adjusted on another machine.
